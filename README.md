## 一、能做什么

| 页面 | 可用的能力 |
|---|---|
| 项目列表 | 4 个真实项目，点开进入项目页 |
| 项目页 · 资料 | 逐份查看解析结果：页段定位、字数、资料类型、全文（可滚动） |
| 项目页 · 项目简报 | 六组字段完整展示（项目背景 / 产品 / 气味 / 商业 / 法规 / 交付）+ 客户额外要求 + 普通条件登记 + 开发上市计划 |
| 项目页 · 子项目 | 全部子项目；**有承袭关系的用叠角呈现**：后来的改香项盖住原项，只露原项一条边（可点） |
| 项目页 · 项目故事 | 叙事摘要 + 时间线（每条带出处）+ 需求覆盖 + 关键决定 / 冲突 / 待确认 / 提示 |
| 子项目页 | 简报、执行条件、需求 ABC（可调整）、筛选与计分（可调开关与弹性）、推荐候选（短名单 / 淘汰 / 详情 / 勾选）、评香决定、部门任务（可推进状态，含前置校验）、右侧终点 / 检查项 / 样品 |
| 香精库 | **真检索**：6,331 条香精，按编号 / 名称 / 品牌 / 品类搜，可直接"用这个"填进评香决定 |
| 标注与标签 | **额外面板**：ABC 定义 → 标签体系 → 每支香精的独立标注 → 每张工单，全部可搜 |
| 调用记录 | 该项目的模型调用记录（节点 / 模型 / tokens / 耗时） |

**用不了的只有一件事**：需要模型的动——上传资料、开始生成、问项目、重新解析。这些按钮是禁用态，鼠标悬停会说明原因。

## 二、ABC 是什么（额外面板里也有完整版）

- **A 主体气味**：这瓶香主要在闻什么。三层：A1 具体气味对象（247 个，柑橘 / 甜橙）→ A2 香族与韵调（29 个，木质 / 花香）→ A3 复合香调（80 个，木质花香调）。
- **B 感受与风格**：闻到它是什么感觉。11 组：光影、温度体感、质地重量、真实度、洁净感、情绪、人格气质、熟悉度、季节时辰、人群印象、通感（共 94 个术语）。
- **C 定位与场景**：卖给谁、用在哪。四个维度 × 12 个内部品类，共 571 个节点：核心定位、常见香型香调、场景风格适配、香气感知与情绪。

三条硬规则：A 必须有独立依据（客户明确目标或主韵，三调只辅助 B/C）；没依据就留空，空映射要写明原因；C 只能取当前品类下的节点。

> 注意：**客户分层 S/A/B/C ≠ 香精本体 A/B/C**。前者是资源与上市优先级，后者是语义分类，两者不能混（面板里有对照表）。

## 五、边界与说明

- **失败不写库**是原系统的规则：这个演示里体现为——终样放行时如果法规 / 质量未完成或检查项没核完，会弹出阻断清单，而不是静默通过。
- **入库关闭**：按钮禁用，与原系统一致。
- **已脱敏**：手机号（138****0000）、收货地址。客户名与品牌名沿用真实记录；如需**对外**演示，建议替换为"某护肤品牌 A/B"并裁掉截图顶部联系人栏（约 30 分钟）。
